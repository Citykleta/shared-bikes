Integración de bicicletas compartidas de Citykleta.

== Description ==

Plugin que añade la gestión de bicicletas compartidas al WordPress de Citykleta,
la plataforma peer-to-peer de alquiler de bicis en La Habana.

Crea un tipo de contenido "Bicicleta" con campos estructurados (modelo, ubicación,
precio por hora y disponibilidad) que se exponen por la REST API para que el
prototipo móvil de Citykleta pueda consumirlos.

== Características ==

* Tipo de contenido personalizado "Bicicletas".
* Campos: modelo, ubicación, precio por hora, disponibilidad.
* Datos accesibles vía la REST API de WordPress.
